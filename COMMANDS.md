# sovereign-mac — Command Reference

Every terminal command run by `sovereign.sh`, organized by module. Nothing is hidden.

> All `defaults write` changes are reversible. To undo any setting, replace `-bool true` with `-bool false` (or vice versa), or run `defaults delete <domain> <key>`.

---

## Reversing Changes

Most settings applied by sovereign-mac use `defaults write` — macOS's standard preference system. Every one of them can be undone.

**To reverse a specific `defaults write` command:**

`defaults delete <domain> <key>`

This removes the key entirely and restores the system default. Example — to re-enable personalized Apple ads:
`defaults delete com.apple.AdLib allowApplePersonalizedAdvertising`

**To reverse a boolean setting without deleting it:**

Replace `-bool false` with `-bool true` (or vice versa) and run the command again.

**Settings that require a restart or logout to take effect:**
- `sudo launchctl config user umask 077` — requires full restart
- Firewall changes (`socketfilterfw`) — take effect after `sudo pkill -HUP socketfilterfw` (already handled by the script)
- Sleep/hibernate settings (`pmset`) — take effect immediately but only apply on next sleep cycle
- Login window changes — take effect on next logout

**Settings that cannot be reversed with `defaults delete`:**
- `/etc/hosts` modifications — restore your backup: `sudo cp /etc/hosts.backup.<date> /etc/hosts && sudo dscacheutil -flushcache && sudo killall -HUP mDNSResponder`
- SSH keys generated by New Machine Setup — delete manually from `~/.ssh/` if needed
- Logs and cache deleted by cleanup — these are gone. That's the point.
- `tccutil reset` — permissions are reset; apps will re-request them on next use (this is expected behavior)

**To check the current value of any setting:**

`defaults read <domain> <key>`

Example: `defaults read com.apple.Safari AutoFillPasswords`

## 1 · Homebrew Maintenance

`brew analytics off`
Disables Homebrew telemetry — stops usage data being sent to Homebrew's servers.

`brew update`
Fetches the latest package index so Homebrew knows what's available.

`brew upgrade --greedy`
Upgrades all installed packages including GUI apps (casks). `--greedy` catches apps that don't auto-update.

`brew cleanup -s`
Removes old versions of packages and clears the download cache.

`rm -rf "$(brew --cache)"`
Force-clears the Homebrew download cache directory entirely.

`brew missing`
Checks for missing dependencies across all installed packages.

`brew autoremove`
Removes packages that were installed as dependencies but are no longer needed.

`brew doctor`
Runs Homebrew's self-diagnostic and flags any installation issues.

`brew list`
Lists all currently installed packages and casks.

`brew uninstall --cask --zap --force <app>` and `brew uninstall --formula --force <package>`
Run from the interactive uninstall picker (Homebrew Maintenance → Uninstall a Package), which lists every installed formula and cask with its size so you can select multiple items by number before confirming. Casks are removed with `--zap` — thorough, goes beyond what a normal uninstall removes. Formulae use the plain formula removal path.

### Sleep Security

`sudo pmset -a destroyfvkeyonstandby 1`
Destroys the FileVault encryption key when entering standby. Prevents cold boot attacks where an attacker extracts your encryption key from RAM while the machine sleeps.

`sudo pmset -a hibernatemode 25`
Enables full disk hibernate — RAM contents written to disk then cleared on sleep. Mode 25 = safe sleep with immediate RAM clearing.

`sudo pmset -a standbydelaylow 0`
Enters standby immediately when battery is below 50%. No delay before the FV key is destroyed.

`sudo pmset -a standbydelayhigh 0`
Enters standby immediately when battery is above 50%. No delay before the FV key is destroyed.

`sudo pmset -a standby 1`
Keeps standby mode enabled. Required for `destroyfvkeyonstandby` to function — if standby is disabled, the key is never destroyed.

`sudo pmset -a powernap 0`
Disables Power Nap — stops background network activity during sleep.

`sudo pmset -a autopoweroff 0`
Disables autopoweroff.

### Reset App Permissions

All reset commands use `tccutil` — macOS's Transparency, Consent, and Control (TCC) system. Resetting a service forces every app to ask for permission again the next time it needs access.

`tccutil reset All`
Resets ALL app permissions. Every app will ask for every permission again. Nuclear option.

`tccutil reset Camera`
Resets Camera access for all apps.

`tccutil reset Microphone`
Resets Microphone access for all apps.

`tccutil reset ScreenCapture`
Resets Screen Recording access for all apps.

`tccutil reset SystemPolicyAllFiles`
Resets Full Disk Access for all apps.

`tccutil reset AddressBook`
Resets Contacts access for all apps.

`tccutil reset Calendar`
Resets Calendar access for all apps.

`tccutil reset Accessibility`
Resets Accessibility access for all apps.

`tccutil reset AppleEvents`
Resets Apple Events automation access.

`tccutil reset SpeechRecognition`
Resets Speech Recognition access.

`tccutil reset MediaLibrary`
Resets Music and Media Library access.

`tccutil reset Photos`
Resets Photos read access.

`tccutil reset PhotosAdd`
Resets Photos add-only access.

`tccutil reset Location`
Resets Location Services access.

`tccutil reset Reminders`
Resets Reminders access.

`tccutil reset Siri`
Resets Siri access.

`tccutil reset Motion`
Resets Motion & Fitness access.

`tccutil reset ContactsFull`
Resets full Contacts access.

`tccutil reset ContactsLimited`
Resets limited Contacts access.

`tccutil reset SystemPolicyDesktopFolder`
Resets Desktop folder access.

`tccutil reset SystemPolicyDocumentsFolder`
Resets Documents folder access.

`tccutil reset SystemPolicyDownloadsFolder`
Resets Downloads folder access.

`tccutil reset SystemPolicyAppBundles`
Resets app bundle access.

`tccutil reset SystemPolicyRemovableVolumes`

`sudo defaults write /Library/Preferences/com.apple.SoftwareUpdate AutomaticCheckEnabled -bool false`
Disables automatic software update checks.

`sudo defaults write /Library/Preferences/com.apple.SoftwareUpdate AutomaticDownload -bool false`
Disables automatic update downloads.

`sudo launchctl disable system/com.apple.softwareupdated`
Disables the software update daemon.

## 6 · MAC Address Spoofer

`networksetup -listallhardwareports`
Lists all network interfaces, device names, and current MAC addresses.

`open "x-apple.systempreferences:com.apple.preference.network"`
Opens System Settings directly to the Network pane. For Wi-Fi, the recommended path is Wi-Fi → (your network) → Details → Private Wi-Fi Address — Apple's own supported, reliable per-network MAC randomization. Manual Wi-Fi spoofing via Terminal is no longer offered, since it depended on Apple's `airport` disassociation tool, which has been removed from current macOS.

`networksetup -setairportpower <iface> off` / `on`
Only run when spoofing a detected Wi-Fi interface via the custom-interface option — toggles Wi-Fi power around the MAC change. Skipped entirely for non-Wi-Fi (e.g. wired/Ethernet) interfaces.

`sudo ifconfig <iface> ether <mac>`
Sets a new MAC address on a specified interface. Confirmed to work reliably on wired/Ethernet and other custom interfaces; Wi-Fi may or may not accept this depending on the Mac and macOS version.

`ifconfig <iface>`
Reads current interface info including MAC address — used to verify the change applied.

## 7 · Encrypted Container Wizard

`hdiutil create -size <size>m -fs APFS -encryption AES-256 -volname <name> -type UDIF <output.dmg>`
Creates an AES-256 encrypted disk image using macOS's built-in encryption. No third-party software required.

`hdiutil attach <path.dmg> -notremovable`
Mounts an encrypted container. macOS will prompt for the password.

`hdiutil detach /Volumes/<name>`
Unmounts (ejects) a mounted container.

`ls /Volumes/`
Lists all currently mounted volumes, including any open encrypted containers.

## 9 · File Search

Search your filesystem and strip metadata from images. Drag a folder into the terminal to set the search location.

`find "$searchdir" -maxdepth 5 -type f -iname "*term*"`
Search by Filename. Searches 5 levels deep, restricted to files (not directories), capped at 100 results.

`rg -FiN "term" "$searchdir"`
Search by Content, via ripgrep. `-F` treats the search term as a literal string, not a regex — pasting something with brackets or parentheses in it won't behave unexpectedly. Skips binary files, capped at 200 matches.

`find "$HOME" -type f -size "$size_spec" -exec stat -f $'%z\t%N' {} +`
Search by Size. Uses `stat` with a tab-delimited format and sorts numerically on raw byte count, rather than parsing `ls -lh` column output — a filename containing a space (extremely common on macOS: `Library/Application Support/...`) would otherwise get truncated by naive field-splitting. Shows the top 50 largest files.

`exiftool -all= -overwrite_original "$imgpath"`
Strip EXIF Metadata. Removes all metadata — GPS location, camera model, serial number, timestamps — from an image. A backup is made first with `_original` inserted before the file extension (`photo_original.jpg`, not `photo.jpg_original`), so the backup itself keeps an extension the OS recognizes and stays openable.

## 10 · Touch ID for sudo

Lets `sudo` accept a Touch ID scan instead of a typed password.

`grep pam_tid.so /etc/pam.d/sudo_local` (or `/etc/pam.d/sudo` on pre-Sonoma)
Checks whether Touch ID is currently configured, and which method — checks `sudo_local` first.

`sudo install -m 444 -o root -g wheel <tmpfile> /etc/pam.d/sudo_local`
Writes the Touch ID PAM line with correct ownership and permissions. Used on macOS Sonoma (14) and later, where `sudo_local` survives OS updates that overwrite `/etc/pam.d/sudo` directly. On macOS 12–13, the script edits `/etc/pam.d/sudo` directly instead, after backing up the original file to `/etc/pam.d/sudo.sovereign-backup`.

Disabling reverses whichever of the two methods was used, removing the `pam_tid.so` line and leaving password authentication as the only method again.
